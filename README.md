# osmoapi

Implements the "Osmocom Control Interface", a programmatic way to interact
with osmocom things like osmo-hlr.

## How do I run it?

I basically followed the [pyo3 getting started guide](https://pyo3.rs/v0.28.3/getting-started.html),
so just look at that (well, the installation bits, then you can just run `maturin develop`).
